## Introduction

The **Factory Production and Quality Control System** is a web-based application developed using Python and Django to manage production jobs, quality inspections, and dispatch clearance in a manufacturing environment.

The system allows users to create and manage production jobs, record product measurements, automatically determine whether products pass or fail quality inspections based on predefined tolerance limits, and review inspection results through approval or rejection.

The application also provides dispatch clearance functionality to help ensure that only eligible production jobs are cleared for dispatch.

This project aims to simplify factory operations, improve quality monitoring, and maintain better control over production and inspection activities.

**Technologies Used:** Python, Django, MySQL, HTML, CSS
